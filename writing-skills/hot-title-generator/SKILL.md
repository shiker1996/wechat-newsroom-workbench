## 生成

### 1. 爆款四要素

| 要素          | 爆款案例             | 不火案例             |
| ------------- | -------------------- | -------------------- |
| 具体人物/IP   | 贾跃亭、字节、Apple  | "服务器安全教程"     |
| 数字冲击      | 暴跌99%、白交几百块  | "26.8k Star"（无感） |
| 情绪钩子      | 下周回国、笑死、扎心 | "藏着掖着"、"心里话" |
| 冲突/反差结构 | 从X到Y、表面X实际Y   | 简单翻车、创意顽疾   |

**四要素齐全爆款率最高。有信息无情绪、有知识无故事，是标题失败的根本原因。**

**⚠️ 数据警示**：根据 30+ 篇公众号阅读数据：

- 四要素全齐 → 推荐流量驱动，**4,000-6,000+ 阅读**（如「外企裁员16%」「钉钉禁止写文档」）
- 仅有数字+人物（无冲突） → 纯资讯标题，**5-11 阅读**（如「国家队重仓DeepSeek」）
- 仅有人物+冲突（无数字） → 情绪文，**~200-800 阅读**
- 仅有数字+时效（无人物无冲突）→ 工具教程，**~800-1,000 阅读**（稳定但上限低）

### 2. 双维度评分

五感法则（传播力）

| 感觉   | 含义                 | 加分 |
| ------ | -------------------- | ---- |
| 数字感 | 有具体金额/比例/人数 | +2   |
| 人物感 | 有具体人物或群体     | +2   |
| 冲突感 | 有矛盾/反转/对比     | +2   |
| 情绪感 | 有情绪词             | +1   |
| 时效感 | 暗示是当下热点       | +1   |

**五感得分 < 6 → 不建议使用**

搜索友好度（搜一搜收录）

| 要求                              | 加分 |
| --------------------------------- | ---- |
| 主旨透明，不悬疑不绕弯            | +3   |
| 含 1-2 个目标搜索词               | +3   |
| ≤22字（过长截断）                 | +2   |
| 无标题党词（震惊/看哭/免费/紧急） | +2   |

**两维度均 ≥4 分才可作主标题。**

### 5. 生成流程

**Step 0：情绪金句先行 ★**
选题原点不应是事件，而是情绪。先写一句「能让人焦虑/愤怒/认同的话」，再用事件去承载它。

与爆款四要素的对应关系：

- 情绪金句（焦虑/愤怒/认同）→ 标题的情绪钩子
- 事件/数据/人物 → 标题的具象感

示例：

- 情绪金句：「你正在被重新工业化」→ 标题「AI监工正在把每个程序员变成流水线工人」
- 情绪金句：「时代真的结束了」→ 标题「外企裁员16%，裁掉的是一种时代」
- 情绪金句：「早不重要，闭环才重要」→ 标题「百度抢先3年做AI搜索，反而输给了Google」

1. 读取素材，提取：**核心情绪 / 对应情绪金句 / 事件 / 数据 / 人物 / 冲突点**
2. 对照**四要素**检查备选标题
3. 按**十大公式**生成 10 个标题（覆盖全部公式），优先采用“情绪 / 口语表达”和“疑问 / 问题钩子”结构，同时保留“工具名 + 用途”结构作为基础选择；允许使用情绪化口语表达（如“笑死”“扎心”）增强记忆点，但必须保证事实准确。
4. 五感打分，<6 分替换；搜索友好度 <4 分不作主标题
5. 逐项过**检查清单**（避坑清单中的 12 种类型逐个对照）
6. **推荐适配检查**：标题能否含「具体人物 + 冲突动词 + 数字」？若不能，标注「⚠️ 推荐不友好」并回 Step 3 重写，直到满足条件或确认确实无法满足（纯资讯类选题建议直接更换选题，而非勉强写标题）
7. 选定双维度均衡（传播≥6 + 搜索≥4）的标题为 `SELECTED_TITLE`

## 筛选

逐项评估，每项 0–2 分：

1. 准确：没有夸大、偷换或超出事实基座
2. 清晰：读者能迅速知道主体和主题
3. 具体：含有效细节，不使用空洞形容词
4. 吸引：存在真实的信息差、影响或张力
5. 搜索：自然包含 1–2 个核心搜索词
6. 适配：符合渠道、受众和正文语气

有事实风险的候选直接淘汰，不参与总分比较。默认微信公众号标题不超过 28 个汉字；用户或下游有更严格限制时从其要求。
