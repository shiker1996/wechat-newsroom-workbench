# R5.2 扩展信任与迁移实施记录

实施日期：2026-08-14

## 结论

R5.2 已完成。工具、远程工具与采集插件的管理操作统一进入本地管理员确认边界；三类扩展均具备来源、权限声明和内容完整性链；legacy 配置迁移、空值语义、秘密摘要及 fallback 下线条件已明确。

## 扩展信任链

- 本地工具插件：安装时校验受信来源声明、权限、包边界和 SHA-256 内容摘要；安装 API 可接收发行方提供的 `expectedContentHash`，不匹配即拒绝。加载时再次比对安装清单摘要。
- 采集插件：安装后记录 SHA-256 内容摘要，运行加载时重新扫描包并比对摘要；Manifest 权限禁止本地路径和外部写入越权。
- 远程工具：规范化 Manifest 后记录 `manifestHash`；可用 `expectedManifestHash` 固定发行方摘要，启用前再次校验目录中的 Manifest 未被篡改。旧目录若没有摘要，不允许直接重新启用，需要重新安装并确认。
- 所有新安装扩展默认停用，权限声明不完整、内容摘要不匹配或来源不可信时不能进入运行态。

## 管理员策略

以下变更统一要求一次性的 `plugin-admin` 本地管理员确认：

- 本地工具、远程工具和采集插件的安装、启停、回滚与卸载；
- 远程工具与采集插件的首次运行授权；
- 远程工具凭据写入或清除；
- 内置工具和内置采集器的运行状态变更。

校验、目录读取、健康检查等只读操作不消耗管理员确认。

## legacy 配置迁移

- 迁移计划在跳过已有统一配置前输出 `differences`，区分统一配置缺字段、普通字段值不同和 legacy 秘密存在；报告不输出秘密原值。
- 迁移配置摘要现在对“普通配置 + 秘密值”整体计算 SHA-256。秘密值变化会改变摘要，但原值不会进入数据库配置 JSON 或公开响应。
- 空值语义固定为：普通字段的空字符串按真实配置值保留并交由 Schema 校验；秘密字段空字符串表示保留已有秘密；legacy 空字符串表示未配置，不迁移。
- legacy fallback 计划在应用版本 `0.7.0` 移除。迁移状态 API 返回 `legacyFallbackRemovalVersion`；只有 `readyToDisableFallback=true` 时才具备提前停读条件。

## 验收覆盖

专项测试位于 `test/r5-extension-trust-migration.test.mjs`，覆盖远程 Manifest 篡改、预期摘要不匹配、迁移字段差异、秘密摘要变化、管理员路由和 fallback 下线版本。
