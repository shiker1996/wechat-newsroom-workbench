# R5.1 主题契约收敛实施记录

实施日期：2026-08-14

## 结论

R5.1 已完成。主题的声明契约、运行时校验、编译器容错、发布对比度门禁和编辑器数值步长已收敛，并新增专项回归测试。

## 实施内容

1. `article.behavior` 与 `social.effects`
   - JSON Schema 继续将两者声明为必填。
   - 运行时校验器现在对缺失对象返回 `REQUIRED`，不再静默放行。
   - 文章与图文编译器保留防御性默认值，确保旧数据或绕过校验的调用不会产生异常或 `NaN` CSS。

2. 数值契约
   - JSON Schema 补登记正式消费的可选 `codePx`，并为基础 token 声明与编辑器一致的 `multipleOf`。
   - 用户主题保存入口启用离散步长校验；直接复制内置主题时先对齐编辑器步长，避免历史内置视觉值阻塞用户副本。
   - `codePx` 继续由图文编译器消费；缺省时回退到 `captionPx`。

3. 对比度门禁
   - 图文门禁根据配方选择实际内容背景。
   - `neon` 配方的半透明 `surface` 先与页面背景合成，再计算正文及组件对比度；这与浏览器最终绘制结果等价，无需引入浏览器 computed-style 扫描。

4. JSON Schema 运行时策略
   - 本阶段不引入新的通用 JSON Schema 运行时依赖。
   - `validateThemeDefinition` 仍是生产入口的规范化运行时校验器，因为它还承担配方目录、目标/来源、密度预算、颜色对比度与封面构图等 Schema 无法单独表达的语义约束。
   - `theme.schema.json` 保留为外部交换、编辑器元数据和契约审计文件；通过测试持续核对关键字段与运行时实现。后续若引入 JSON Schema 引擎，应作为第一层结构校验，不能替代语义校验器。

## 验收覆盖

- 缺失 `behavior` / `effects` 会被运行时拒绝。
- 绕过校验的旧定义仍能稳定编译，CSS 不含 `NaN` 或 `undefined`。
- 用户导入/保存的非步进数值会返回 `STEP_MISMATCH`。
- 半透明内容面使用合成后的真实色值执行对比度门禁。
- Schema、覆盖矩阵与编译器均登记 `codePx` 的实际状态。

专项测试位于 `test/theme-contract-r5.test.mjs`。
