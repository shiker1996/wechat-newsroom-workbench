# Social 图文拆页与补充块装箱优化：阶段 1 实施记录

> 阶段：统一页面容量估算与拆页判断
>
> 日期：2026-08-22

## 已实施内容

### 1. 页面估算支持视觉块与结构块双口径

`estimateSocialCardPageLoad` 现在同时返回：

- `structuralBlockCount`：用于模板硬上限；
- `visualBlockCount`：用于高度估算；
- `nearFit`：代码面板合并后处于近似容量区间，交由浏览器审计确认；
- `nearFitRatio`：近似容量比例。

相邻代码块可以在估算时按一个视觉代码面板计算，但结构性 block 数量仍按原始故事板块数校验。

### 2. 相邻代码块先合并再判断拆页

重排层会优先尝试合并相邻代码块：

```text
安装命令 + 启动命令 + 快捷键说明
              ↓
安装与启动代码面板 + 快捷键说明
```

如果合并后的估算只略高于静态安全线，则不立即拆页，而是保留当前计划，让浏览器布局审计裁决真实是否溢出。

### 3. 拆页仍保留硬门禁

以下情况仍会触发确定性拆页：

- block 数量超过模板结构上限；
- item 数量超过模板结构上限；
- 估算高度明显超过页面内容区；
- 没有可合并或可安全拆分的语义单元。

`nearFit` 只放宽“接近容量边界”的预检，不会绕过最终浏览器审计。
