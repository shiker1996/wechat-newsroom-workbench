# 封面视觉组件映射

> 本文件由 `article-cover-ai-visual-generator` 运行时作为内置参考注入，不复制到候选工作目录，也不属于 `workspace.files`。本文件只负责把文章语义和主题线索转译成可见视觉组件。

## 生成前的判断顺序

1. 从标题、摘要和 `coverSemantics` 识别文章的唯一核心：事件、产品、人物、趋势、数据、争议、观点或方法；
2. 为核心选择一个主视觉表达；
3. 视需要选择辅助表达，让画面形成视觉平衡；辅助表达的位置和数量由 Agent 自行决定；
4. 使用主题 SPEC 的颜色、纹理、边框、形状和装饰语言完成变体；
5. 检查整张封面是否仍然只剩左侧文本和角落装饰。

## 语义到组件的建议

| 文章语义 | 主视觉方向 | 辅助视觉方向 |
| --- | --- | --- |
| 科技、AI、系统、网络 | 网络节点、线路、终端结构、模块关系 | 结构化面板、网格、轨道或信号线 |
| 产品、平台、工具 | 产品轮廓、界面抽象、模块卡片 | 产品面板、功能层叠或品牌几何 |
| 数据、规模、变化 | 大数字、比例结构、柱线或刻度抽象 | 数据面板、趋势线或分层色块 |
| 事件、行业、趋势 | 时间切片、方向箭头、新闻版式、变化轨迹 | 事件节点、地图/轨道抽象或对比色块 |
| 人物、组织、观点 | 引语结构、姓名字标、观点关键词 | 肖像替代几何、徽章、光圈或版心图形 |
| 风险、争议、限制 | 警示框、断裂线、对撞色块、边界线 | 封闭结构、裂变形状或对比面板 |
| 方法、步骤、机制 | 流程轨道、节点关系、连接关系 | 步骤面板、路径、箭头或模块堆叠 |

## 组件选择原则

- 主视觉要表达文章核心，不要只做抽象背景；
- 辅助视觉应服务于主题和层级，不要为了填空而添加；
- 视觉表达可以抽象，但必须能从文章主题和主题 SPEC 解释，位置不做规定；
- 视觉隐喻候选只是灵感，Agent 可以组合、替换、简化或完全不采用；
- 选定视觉隐喻后，优先将其发展为由形状、线条、纹理、尺度、重复或色块组成的完整视觉系统；单个小图标、孤立细线或角落点缀不能承担主视觉；
- 不能为了提高占用率虚构数字、图表数据、人物肖像或产品界面细节；
- 小标签、细线、点阵和单个圆形只能作为辅助层，不能单独充当右侧主视觉。
