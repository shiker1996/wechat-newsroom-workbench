# 公众号文章封面布局指南

> 本文件由 `article-cover-ai-visual-generator` 运行时作为内置参考注入，不复制到候选工作目录，也不属于 `workspace.files`。本文件只负责 900×383 横向封面的几何、间距、视觉占用和构图平衡。

## 1. 画布与安全区

| 项目 | 规范 |
| --- | --- |
| 设计尺寸 | 900 × 383px |
| 横向安全区 | 左右各 40–56px |
| 垂直安全区 | 上下各 28–40px |
| 主标题字号 | 34–58px，按标题长度和主题层级调整 |
| 摘要字号 | 14–20px |
| 信息行字号 | 11–15px |

`.page` 只负责固定画布和背景边界。可以裁切背景装饰，但不要用裁切、隐藏溢出、透明文字或内部滚动掩盖标题、摘要和信息行。

## 2. 横向构图基线

封面应先决定一个主构图，再安排文字和视觉元素。以下方向只是可选灵感，应按主题 SPEC 和文章语义自由变体化，不是固定模板，也不是必须达到的比例：

- `split`：文字区和视觉区形成可读的空间关系；
- `full-bleed`：主视觉铺满画布，文字放在明确的对比层或框景中；
- `asymmetric`：主标题偏左或偏右，另一侧由主题图形、色块或信息结构形成重量；
- `frame`：边框、版心或印刷层构成完整画面，文字和图形共同落在版心内；
- `data-panel`：一侧为标题，另一侧为有面积的图表抽象、数据面板或结构化图形。

画面不能只剩标题和无意义空背景、小圆点或细线。应根据文章语义与主题 SPEC 形成至少一个可辨认的主题相关视觉表达，例如主题色块、抽象图形、网络结构、轨道系统、产品界面抽象、图表面板或大面积纹理；表达可以位于左、右、中央、顶部或底部，由 Agent 自行判断，不要求固定位置、方向、面积或组件。

## 3. 有效视觉占用

- 文字、色块、边框、图形、纹理和信息结构共同形成有效视觉重量；空容器、弹性高度和低对比伪元素不计入；
- 横向封面的整体有效视觉占用建议达到画布宽度的 65%–90%，允许保留 10%–35% 呼吸留白；
- 低信息量标题可以留白，但必须有明确主焦点和第二视觉层；
- 不要用重复文案、虚构指标或无意义装饰填充空间；优先放大已有标题、摘要和主题语义对应的视觉表达。

以上占用目标是软性的设计参考，不是运行时门禁。比占满画布更重要的是：标题、摘要和信息行完整可读，视觉隐喻形成相互关联的整体，留白不来自溢出或内容挤压。

视觉隐喻不应退化成一个孤立的小图标。选定隐喻后，应通过至少两种相互关联的视觉手段（例如形状与线条、色块与纹理、节点与路径、尺度与重复）形成一个可辨认的图形系统；具体位置、方向、面积和组件由 Agent 自行决定。

## 4. 层级与节奏

每张封面至少形成：

1. 一个第一视觉焦点：标题或主题主视觉；
2. 一个第二视觉层：摘要、主题图形、色块、边框、数据抽象或信息标签；
3. 一个弱信息层：品牌、日期或短标签。

主标题应在第一眼可识别，摘要和信息行不能与标题争夺最大字号。文字区域与视觉区域应共享同一条对齐轴、边界或色彩关系，不要像两个互不相关的模块。

## 5. 实现建议

- 使用 `display:grid`、`display:flex` 或明确的绝对定位区域表达构图关系；
- 为文字和视觉元素分配可解释的空间关系，具体区域数量、位置和宽度由构图自行决定；
- `max-width` 用于控制换行，不应把整个页面压缩成一条左侧文本；
- 主题主视觉应有足够面积和对比度，在 900×383 原尺寸下仍可辨认；
- 不要依赖 `space-between`、负 margin、内部滚动、隐藏溢出或过度压缩制造所谓的视觉密度；
- 主题 SPEC 决定颜色、纹理、边框和装饰语言，本指南决定空间关系，不要把本指南渲染成页面正文。
