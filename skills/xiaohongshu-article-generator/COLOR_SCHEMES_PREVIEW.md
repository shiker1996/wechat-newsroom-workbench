## 🔥 hot - 热点争议配色

**适用话题：** 绩效改革、裁员风波、薪资爆料、大厂争议

### 配色参数
```css
background:
  from: #2d132c (深酒红)
  mid: #801336 (中酒红)
  to: #c72c41 (亮酒红)

accent:
  primary: #f9a826 (金黄色)
  secondary: #ff8c00 (深橙色)
  highlight: #ffd700 (黄金色)
```

### 视觉效果
- 🔥 红橙渐变背景 - 营造热烈、争议氛围
- 💰 金色强调色 - 贴合薪酬、金钱话题
- ✨ 发光效果 - 增强视觉冲击力

### 匹配关键词
绩效、裁员、薪资、年终奖、争议、爆料、八卦、热点、改革、调整

## 🔧 使用方式

### 方式 1：自动匹配（推荐）
```javascript
import { matchColorScheme } from './color-schemes.js';

const scheme = matchColorScheme(
  '字节绩效套改！M 不再是平庸？',
  '期权激励 年终奖 薪酬改革'
);
// 返回：hot 方案（红橙色系）
```

### 方式 2：手动指定
```javascript
{
  topic: '字节绩效',
  colorScheme: 'hot'  // hot/career/finance/emotion/...
}
```

### 方式 3：CSS 变量
```css
:root {
  --bg-from: #2d132c;
  --bg-mid: #801336;
  --bg-to: #c72c41;
  --accent-primary: #f9a826;
  --accent-secondary: #ff8c00;
}
```
