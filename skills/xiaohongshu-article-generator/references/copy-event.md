# 事件图文配套文案规则

只负责已锁定事件故事板的对外文案，不重新安排时间线、证据页、回应页或事实边界页。

## 输出形态

纯文本，直接可发布：不使用 Markdown 或 HTML 标记（标题、加粗、列表符号、链接语法一律禁止），结构只用分行、空行和数字编号表达；公众号与小红书图文均不渲染标记文案。

## 表达目标

- 结论前置，但传播张力不得高于证据强度。
- `confirmedFacts` 可以作为陈述句，关键事实保留来源编号或来源归属。
- `claims` 必须保留说话者，并使用“声称”“据其发布”“尚未获独立证实”等表达。
- `authorContext` 只能作为作者观点，不得并入事实。
- 来源冲突、回应缺失和开放问题必须明确保留。

## 渠道

- 公众号：信息密度优先，适当添加话题标签。
- 小红书：可以缩短句子和适度使用 emoji，但不得娱乐化高风险事件。

不得用问号或引号暗示未经证实的定性，不得推断动机、违法性或责任，不得煽动网暴。结尾只邀请理性讨论或继续关注公开进展。
