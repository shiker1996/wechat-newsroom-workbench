# 自定义图文配套文案规则

只负责已锁定教程、清单或观点故事板的对外文案，不重新设计故事线和页面结构。

## 输出形态

纯文本，直接可发布：不使用 Markdown 或 HTML 标记（标题、加粗、列表符号、链接语法一律禁止），结构只用分行、空行和数字编号表达；公众号与小红书图文均不渲染标记文案。

## 来源等级

- `author_experience`：可以写成作者第一人称亲历。
- `user_material`：必须保留来源归属。
- `model_suggestion`：只能写成建议或参考，不得写成亲测、效果、收益或数据。

没有 `author_experience` 时，全文禁止“我用了”“亲测”“踩坑”等亲历措辞。数字、效果和收益必须有用户素材支持；个人判断不得写成行业共识。

## 渠道

- 公众号：短句分块、信息明确，结尾自然承接句和 6–8 个准确话题标签。
- 小红书：允许更强的首句钩子、克制 emoji 和 6–8 个准确话题标签。

教程保留前置条件和风险提示；清单保留筛选标准与适用边界；观点保留反方与不确定性。
