## 🧱 布局结构

本文件是 AI 视觉页面布局 CSS、尺寸、间距和对齐规则的唯一来源。`references/xhs-visual-contract.md` 只规定 DOM 结构和组件职责，不重复定义本节 CSS。

```html
<section class="page">
  <div class="page-inner">
    <header class="neon-topbar"> <!-- 顶部栏 --> </header>
    <div class="page-body">
      <div class="page-content-stack"> <!-- 纵向内容栈和卡片间距 --> </div>
    </div>
    <div class="bottom-strip">    <!-- 底部导航 --> </div>
  </div>
</section>
```

```css
*, *::before, *::after {
  box-sizing: border-box;
}
.page {
  width: 375px;
  height: 667px;
  /* 仅用于固定画布和背景装饰的边界；不能用来隐藏内容 */
  overflow: hidden;
  position: relative;
  padding: 18px 16px 16px;
}
.page-inner {
  height: 100%;
  padding: 0;
  display: flex;
  flex-direction: column;
}
.page-body {
  min-height: 0;
  flex: 1;
  display: flex;
  flex-direction: column;
  justify-content: center;
  overflow: hidden;
  padding: 4px 0 7px;
}
.page-content-stack {
  width: 100%;
  min-width: 0;
  min-height: 0;
  display: flex;
  flex-direction: column;
  /* 8px 是通用基线；主题可在 8–16px 范围内调整 */
  gap: 8px;
}
```

内容页必须把所有纵向卡片、标题和辅助层放入 `.page-content-stack`，不要让多个卡片直接成为 `.page-body` 的兄弟元素。`.page-body` 负责页面可用区和垂直对齐，`.page-content-stack` 负责内容层的纵向排列和卡片间距；主题 SPEC 可以覆盖 gap，但不能省略该布局职责。

## 🔤 字体规范

以下是 AI 视觉页面的字号范围参考；主题 SPEC 可在保持可读性和布局门禁的前提下调整字体风格与档位：

| 类型 | 字号 | 字重 |
|------|------|------|
| 封面标题 | 28-40px | 800-900 |
| 页面标题 | 14-18px | 700-800 |
| 卡片标题 | 13-16px | 700-800 |
| 正文 | 11-15px | 400-500 |
| 辅助文字 | 10-12px | 400 |
| 标签 | 10-11px | 600-700 |

行高：标题 1.2-1.4，正文 1.5-1.7

## 📏 间距系统（8px 基准）

页面采用两层固定布局基线：`.page` 负责 `18px 16px 16px` 的画布安全区，`.page-inner` 保持 `padding:0`，`.page-body` 负责 `4px 0 7px` 的正文呼吸空间。主题可以通过自身组件和背景装饰表达差异，但不要把页面安全区迁移到 `.page-inner`，也不要删除正文区域的第二层 padding。

| 类型 | 数值 |
|------|------|
| 超小间距 | 4px |
| 小间距 | 8px |
| 中间距 | 12px |
| 标准间距 | 16px |
| 大间距 | 24px |

## 🎨 页面视觉占用目标

| 视觉占用 | 建议 |
|--------|------|
| 60%-80% | ✅ 内容页的优先目标 |
| 45%-60% | ⚠️ 事实较少时可接受，但必须有明确强焦点 |
| 80%+ | ⚠️ 继续确认文字可读性和安全边界 |

上表是生成阶段的视觉目标，不是运行时门禁，也不要求用空白卡或重复内容填满页面。视觉占用指真实可见内容和组件形成的视觉重量，不把装饰伪元素、空容器或 `.page-body` 的弹性高度当成内容。

| 页面类型 | 视觉建议 |
|----------|------------|
| `cover` | 45%-75%，保留标题和主题留白 |
| `content` | 60%-80%，优先 3–4 个有效内容层 |
| `ending` | 35%-70%，突出结论或行动提示 |

内容较少时可以低于建议值，但整组不能让所有页面都只有一小条内容；优先放大真实焦点、增加已有关系的可视化承载或提高组件内在层次。不要为了追求视觉占用添加空白卡、重复文案或无意义装饰填充。

生成阶段不执行运行时布局审计；Agent 只需按本指南和视觉契约完成可读、完整、不过度拥挤的页面。

封面审计以 `.cover-center` 和 `.cover-bottom` 的实际可见子元素为内容边界，不把 `cover-center` 的 `flex:1` 全高当成已用内容；顶部角标属于装饰层，不单独撑高利用率。

## 📱 适配要点

- **顶部安全区**：避免被小红书 UI 遮挡，建议 padding-top: 36px（非 page-cover 页面）
- **底部安全区**：避免被点赞/评论栏遮挡，建议 padding-bottom: 42px
- **整体垂直居中**：封面、内容页和结尾页的内容栈统一居中，卡片内部文字仍按语义默认左对齐

## 🧠 内容排版原则

1. **一页只讲一个重点**，不要一页塞完整篇文章
2. **单段不超过 4 行**，保持呼吸感
3. **内容过多时优先拆页**，不压缩字体/行高
4. **留白是视觉缓冲，不是浪费**
5. **cover / 金句页**：留白 30%-45%，大字
6. **内容页**：事实允许时让真实内容形成内容区 60%-80% 的视觉占用；不要把几张小卡集中在中部，也不要用空白卡或无意义装饰填充
7. **辅助文字和标签最小不低于 10px**，正文最小 ≥11px；这与浏览器审计规则一致
8. **整组垂直对齐统一**：封面、普通内容页和结尾页的 `.page-body` 均整体垂直居中；卡片内部文字仍默认左对齐
9. **每页一个首要焦点**：数字、证据、人物、步骤或结论中只选择最符合本页职责的一种作为最大视觉层，其他信息降为次级层
10. **相邻页面保持节奏变化**：主组件类型、强调位置、卡片轮廓或明暗层级至少有一项不同；事实结构相同且重复最合理时不强制变化
11. **主题化强调**：数字焦点、证据卡和结论色块使用当前主题的 `accent / accent2 / surface / inverse`，不固定蓝橙色，也不靠无意义 Emoji 制造变化
