# 事件图文故事板

只负责 `social-event` 入口的故事板规划。

## 输入

输入契约为 `social_card_fact_base`，内容类型必须是 `event`。只使用确认事实、带来源的主张、回应、时间线和来源审计。

## 输出

输出契约为 `social_card_storyboard`。传播张力不得高于证据强度：

- 确认事实可以陈述，但关键事实应保留来源编号。
- 未核实主张必须保留说话者和不确定性表达。
- 多方回应存在时单独组织。
- 至少一页说明来源缺口、争议和开放问题。
- 不得推断动机、违法性、责任或因果关系，不得诱导网暴。

只输出严格 JSON，不输出发布文案、HTML、CSS 或截图指令。具体规则见 `references/storyboard.md`。
