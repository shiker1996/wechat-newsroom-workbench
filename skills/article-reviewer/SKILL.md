# 文章审阅与修订

先修复高风险问题，再优化表达。保留作者核心立场，但不保留无依据的事实或有害表述。

## 输入

优先读取原文、事实基座、发布渠道、目标读者和改写范围。材料不完整时继续审阅，并把无法验证的内容标为待核实；不要自行补造证据。

编排模式同时读取 `02-outline.md` 的事实基座和 `05-humanized.md`，写入 `06-reviewed.md`。

## 审阅顺序

1. **事实**：拆分可核验主张，检查来源是否直接支持、时效是否适用、引语是否准确、数字口径是否一致。
2. **边界**：区分事实、消息来源说法、作者推断和价值判断；不得把推断改写成确定事实。
3. **论证**：检查因果跳跃、样本偏差、遗漏前提、内部矛盾和最强反方解释。
4. **标题**：检查标题承诺是否由正文兑现，是否夸大或遗漏关键限定。
5. **风险**：检查隐私、名誉、歧视、医疗/法律/金融误导、版权和大段近似表达；只指出风险，不作法律结论。
6. **表达**：修复歧义、重复、模板腔和节奏问题，不把文章统一改成审稿人的声音。

## 严重度

- `blocker`：发布可能造成重大事实、法律或安全风险
- `major`：核心论点、标题或重要事实存在问题
- `minor`：局部逻辑、表达或格式问题

关键事实引用覆盖率按“具有直接支持来源的关键事实数 ÷ 关键事实总数”计算。无法访问或核验来源时不要计为已覆盖。

## 输出

独立审稿时先给结论和问题清单，再给修订稿。编排模式下先写可发布修订稿，并在文末保留唯一内部注释：

```markdown
<!-- REVIEW
result: pass|needs-revision
blocker: 0
major: 0
minor: 0
verified_facts: 0
citation_coverage: 100%
remaining_risks: none
return_to: none|outline|titles|draft
-->
```

存在 `blocker` 或未解决的 `major` 时使用 `needs-revision`，并准确指定返工阶段。不要在正文中留下审稿报告标题。
