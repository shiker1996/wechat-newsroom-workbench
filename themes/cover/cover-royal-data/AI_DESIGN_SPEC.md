# 宝蓝数据 · Cover AI Design Spec

> 主题 ID：cover-royal-data · 版本：1.0.0 · 目标：公众号封面 AI HTML/CSS 视觉生成

## 主题定位

宝蓝深底配青蓝与鎏金点缀，理性、清晰并带有数据图表感。适合数据对比、榜单、金额、比例、版本变化和需要快速识别数字重点的文章。

宝蓝是稳定画布，青蓝用于数据焦点、线条和局部面板，鎏金只强调一个关键数字或结论。颜色不能替代事实，也不能凭颜色暗示增减方向。

## 字体与标题气质

正文和标题使用 sans。标题适合左对齐、数字或期限的有限高亮和类似报告封面的结构感；英文、型号和数字要保留原文。字号和具体断行由运行时实测决定。

## 背景与图形语言

使用网格、坐标线、斜切面、刻度、细折线和深色代码表面。图形可以像数据仪表盘，但不绘制未经输入的坐标、比例和趋势箭头。

## 推荐构图

标准主题构图提示为 diagonal-split，组件线索包括 canvas / right-panel diagonal code / title / subtitle / meta / bottom-left grid。AI 可以采用右侧数据面板、斜切图表感或横向报告构图，主标题仍需最醒目。

## 标题区与留白

标题使用近白色，核心数字或关键词使用青蓝，只有一个结论点可以使用鎏金。副标题使用浅蓝灰，装饰坐标线和网格不得穿过文字。

## 可见装饰

优先使用网格、刻度、短柱、折线轮廓和小型数据标签。所有装饰必须是抽象背景，不得输出新的数字、百分比或排名。

## 应避免的退化

- 不要凭空画出数据图表或趋势结论；
- 不要让装饰数字与真实标题数字混淆；
- 不要使用泛化金融 K 线、货币或上涨箭头；
- 不要把封面做成仪表盘截图；
- 不要使用脚本、远程资源、外链字体或外链图片。
