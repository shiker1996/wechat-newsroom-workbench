# 石墨荧光 · Cover AI Design Spec

> 主题 ID：cover-graphite-neon · 版本：1.0.0 · 目标：公众号封面 AI HTML/CSS 视觉生成

## 主题定位

石墨深底配荧光绿和青绿色，表达硬核、直接、工程化的开发者气质。适合技术教程、工程实践、工具变化和需要突出机制或版本信息的文章。

## 配色关系

| 语义 | 实际颜色 | AI 侧变量参考 |
| --- | --- | --- |
| page | #202124 | `var(--page)` |
| text | #F2F2EF | `var(--text)` |
| muted | #9C9C94 | `var(--muted)` |
| accent | #B8E62E | `var(--accent)` |
| accentSecondary | #4EE1C1 | `var(--accent-secondary)` |
| inverseText | #202124 | `var(--inverseText)` |
| codeBackground | #161617 | `var(--codeBackground)` |

石墨作为背景和代码表面，荧光绿只用于机制焦点、关键词或斜切色块，青绿色用于第二层关系。荧光效果应克制，保证正文对比度。

## 字体与标题气质

正文和标题使用 sans。标题适合左对齐、短行、工程日志式眉题和明确的关键词高亮；可以出现轻微终端或命令行气质，但不得把标题变成代码。

## 背景与图形语言

使用斜切分割、网格、细线、终端边框、巨大首字和少量荧光边缘。允许有轻微扫描线或线性渐变，但不可使用大面积霓虹光晕。

## 推荐构图

标准主题构图提示为 diagonal-split，组件线索包括 canvas / left-half diagonal span / title / subtitle / giant-char / meta。AI 可以做左右斜切、终端面板或工程标记，但只保留一个主机制焦点。

## 标题区与留白

标题使用浅灰白，关键动作或版本号使用荧光绿；副标题使用灰色，信息行保持最弱。巨大首字和斜切边界必须避开标题字面，不能造成断字错觉。

## 可见装饰

优先使用网格、角标、代码括号、细刻度、斜线和大号首字。装饰需要在缩略图中形成明确轮廓，不要只靠极低透明度的发光。

## 应避免的退化

- 不要伪造终端输出、版本号、性能数字或代码；
- 不要使用泛化机器人、芯片或电路图片替代文章内容；
- 不要把所有元素都做成荧光绿；
- 不要让大字装饰与真实标题混淆；
- 不要使用脚本、远程资源、外链字体或外链图片。
